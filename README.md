# 半寸

少看秤,多看寸。一款轻量化减脂可视化陪伴工具:每天记一次体重,用简约线稿看见三十天后的可能轮廓。

> 所有模拟结果均为理想化参考,不是对真实身体变化的预测,也不构成医疗或营养建议。

## 运行

纯静态页面,没有构建步骤。在本目录启动任意静态服务即可,例如:

```
python -m http.server 8765
```

然后打开 http://127.0.0.1:8765/index.html 。数据只保存在浏览器本机(localStorage),不上传。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` / `styles.css` / `app.js` | 页面、样式和全部逻辑 |
| `app.js` 中的 `TPL` | 人体轮廓模板点,取自参考图的外轮廓 |
| `app.js` 中的 `BODY_MODEL` | 体重变化 → 各部位围度变化的小模型,由**合成数据**拟合,仅供参考 |
| `template.json` | 早期模板参数,目前 `app.js` 并不读取它 |
| `验收报告.md` | 各轮改动与验证记录 |

## 已知限制

- 每日提醒只在页面打开时生效(静态网页无法后台提醒)。
- 数据只存在浏览器本地,清除浏览器数据会丢失,请用 设置 → 备份与恢复 定期备份。
- BODY_MODEL 由合成数据拟合,轮廓差异在图上默认放大约 2.5 倍(界面有标注),实际变化更小。
